==================================================
FILE 76 - API PRODUCT RESPONSE
==================================================

Goal:
Prepare product data for the API/frontend layer.

Input:
Customer query

Process:

Customer Query
    ↓
Recommendation Engine
    ↓
Normalized Product Data
    ↓
Product Matching
    ↓
API Response
    ↓
Frontend

Response:

{
    "success": true,
    "query": "...",
    "filters": {},
    "keywords": [],
    "product_count": 5,
    "products": []
}

Each product contains:

- name
- price
- in_stock
- stock_label
- categories
- tags
- description
- image
- url

Important:
Stock status comes from the normalized
product data.

Unknown stock remains:
"Stock Unknown"
