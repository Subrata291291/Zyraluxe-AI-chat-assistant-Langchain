============================================================
FILE 59 - LLM PRODUCT QUERY PARSER WORKFLOW
============================================================

Purpose:
Use Gemini to understand natural language product requests.

Input:
Customer's natural language query.

Process:

Customer Query
      ↓
Gemini
      ↓
Structured JSON Filters
      ↓
Product Search
      ↓
Product Ranking

Possible Filters:

query
category
max_price
in_stock

Example:

Customer:
"I need oxidized earrings under 300 that are available"

Output:

{
    "query": "oxidized",
    "category": "earrings",
    "max_price": 300,
    "in_stock": true
}
