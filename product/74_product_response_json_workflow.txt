==================================================
FILE 74 - PRODUCT RESPONSE JSON
==================================================

Goal:
Convert product-card data into a clean JSON response.

Input:
Customer query

Process:

Customer Query
    ↓
File 73
    ↓
Complete Product Cards
    ↓
JSON Response
    ↓
Frontend

Response Structure:

{
    "query": "...",
    "filters": {},
    "keywords": [],
    "product_count": 5,
    "products": []
}

Each product contains:

- name
- price
- in_stock
- stock_label
- categories
- tags
- description
- image
- url

Purpose:

The frontend can consume this JSON
and create product cards without
knowing the internal search logic.
