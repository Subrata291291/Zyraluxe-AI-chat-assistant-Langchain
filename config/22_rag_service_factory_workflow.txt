Factory Pattern
---------------

Instead of creating components
everywhere:

File A → create LLM
File B → create LLM
File C → create LLM

Use:

Factory
   ↓
create_llm()
   ↓
LLM


Benefit
-------

Centralized component creation
        ↓
Cleaner architecture
        ↓
Easier model replacement
        ↓
Easier testing
